Automatic Case Linking: Add @LOC-1 to any automated test title to automatically link runs to existing test cases!
Option 1: Zero-Config CLI Runner
Executes your tests with live console output, bundles failure screenshots, and submits the batch upon exit:
npx kobean run --playwright "npx playwright test"
Option 2: Native Reporter (playwright.config.ts)
Add `@kobean/cli/playwright` to your reporters list:
import { defineConfig } from '@playwright/test'; export default defineConfig({ reporter: [ ['list'], ['@kobean/cli/playwright', { uploadScreenshots: true }] ], use: { screenshot: 'only-on-failure' } });
Option 1: Zero-Config CLI Runner
Run Cypress headless and automatically ingest test outcomes:
npx kobean run --cypress "npx cypress run"
Option 2: Plugin Hook (cypress.config.ts)
Register in `setupNodeEvents`:
import { defineConfig } from 'cypress'; import { kobeanCypressPlugin } from '@kobean/cli/cypress'; export default defineConfig({ e2e: { setupNodeEvents(on, config) { kobeanCypressPlugin(on, config); }, }, });
Option 1: Zero-Config CLI Runner
npx kobean run --vitest "npx vitest run"
npx kobean run --jest "npm test"
Option 2: Reporter Configuration
Add `@kobean/cli/jest` to `jest.config.js` or `vitest.config.ts`:
// vitest.config.ts or jest.config.js export default { reporters: [ 'default', ['@kobean/cli/jest', { uploadScreenshots: true }] ] };
Option 1: Zero-Config CLI Runner
Runs Pytest and ingests xunit2 XML results automatically:
npx kobean run --pytest "pytest"
Option 2: Standalone Report Ingest
Upload pre-generated JUnit XML reports:
pytest --junitxml=results.xml && npx kobean report --file results.xml
Cucumber BDD JSON Ingestion
Cucumber exports scenarios, steps, and base64 embedded screenshot failure attachments:
npx cucumber-js --format json:report.json && npx kobean report --format cucumber-json --file report.json
