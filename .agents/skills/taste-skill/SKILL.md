# Taste-Skill Workflow

Whenever you generate or modify a UI component:
1. Run through the checklist in `visual-audit.md`.
2. Inspect borders, typography tracking, icon stroke consistency, and contrast.
3. Eliminate any heavy drop shadows, rounded-3xl toy styling, or unconstrained color confetti.
4. Verify that numbers use `tabular-nums`.
5. Ensure keyboard focus rings are visible and functional.
